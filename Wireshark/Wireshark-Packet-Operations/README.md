# Wireshark: Packet Operations

## Overview

This TryHackMe room focused on the fundamentals of packet analysis using Wireshark and introduced more advanced techniques for investigating network traffic at the packet level.

The room built on the knowledge gained from Wireshark: The Basics and focused on using Wireshark statistics, filters, operators, and functions to investigate network traffic.

## Learning Objectives

- Investigate network traffic captures
- Use Wireshark statistics to understand captured traffic
- Apply packet filtering techniques
- Use protocol filters
- Apply advanced filtering techniques
- Investigate packets at a deeper level

## What I Learned

### 1. Packet Analysis

I learned how to investigate network traffic at the packet level using Wireshark.

Packet analysis allows an analyst to examine individual packets and identify useful information such as source and destination addresses, protocols, ports, and packet characteristics.

### 2. Wireshark Statistics

I learned how Wireshark statistics can provide a high-level overview of captured traffic.

Statistics can help analysts understand the protocols, conversations, endpoints, and general behaviour present within a packet capture.

This provides a useful starting point before investigating individual packets.

### 3. Packet Filtering

I learned how to use Wireshark filters to narrow down large packet captures and focus on relevant traffic.

Filtering makes investigations more efficient by reducing unnecessary packets and allowing analysts to focus on specific protocols, hosts, ports, or packet characteristics.

### 4. Protocol Filters

I practised using protocol-based filters to isolate specific types of network traffic.

This is useful when investigating protocols such as:

- TCP
- UDP
- HTTP
- DNS
- ICMP

Protocol filtering helps analysts quickly identify traffic related to a particular investigation.

### 5. Advanced Filtering

I learned how advanced Wireshark filters can be used to perform more specific packet investigations.

Advanced filtering allows analysts to combine conditions and search for particular packet characteristics instead of manually examining an entire capture.

This is especially useful when dealing with large PCAP files.

### 6. Operators and Functions

I learned how Wireshark filtering operators and functions can be used to create more precise display filters.

Using these features makes it possible to perform more detailed searches and identify specific patterns within network traffic.

## Practical Skills

## Security Relevance

Packet analysis is an important skill for a SOC analyst.

During a security investigation, analysts may need to examine large amounts of network traffic to determine what happened during an incident.

Wireshark filtering and statistics can help analysts quickly identify relevant packets, investigate suspicious communications, and understand network activity.

## Key Takeaways

The main lesson from this room was that effective packet analysis requires more than simply looking at individual packets.

Using Wireshark statistics and filtering techniques makes it possible to move from a large packet capture to specific traffic that requires investigation.

I also learned that advanced filtering can significantly improve the efficiency and accuracy of network investigations.
