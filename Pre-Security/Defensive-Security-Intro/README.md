# What I Learned

## What is Defensive Security?

Defensive security focuses on protecting an organization's systems, networks, and data from cyber attacks.

Rather than finding vulnerabilities like offensive security, defensive security aims to prevent attacks, detect suspicious activities, and respond effectively when incidents occur.

---

## Threat Intelligence

Threat intelligence is the process of collecting, analyzing, and sharing information about cyber threats.

Security teams use threat intelligence to understand attacker behavior, identify emerging threats, and improve their defenses before attacks occur.

---

## Responsibilities of Defensive Security Teams

Common responsibilities include:

- Monitoring security events
- Investigating suspicious activities
- Responding to incidents
- Protecting systems and networks
- Improving security controls

---

## Why Defensive Security Matters

Organizations face cyber threats every day. Defensive security helps reduce risk by detecting attacks early, minimizing damage, and maintaining the confidentiality, integrity, and availability of systems.
